## Preprocessing, feature extraction & selection
- **Feature set:** `FEATURE_COLS` — comprehensive physiological + labs + demographics (see [algorithm/sepsis_causal_project/src/sepsis_causal/constants.py](algorithm/sepsis_causal_project/src/sepsis_causal/constants.py)).
- **Missing data handling:** forward-fill along time, then mean-impute remaining values using train-split feature-wise means. Implementation in `_forward_fill_then_mean_impute` in `prepare.py`.
- **Normalization:** feature-wise mean/std computed only from observed training values (`_fit_normalization_stats`) and stored in `prepared/normalization_stats.json`.
- **Augmented channels:** observation mask (binary) and delta (time-since-last-observation, capped by `delta_cap_hours` and normalized). Final input per timestep is concatenation: normalized values | obs mask | delta.
- **Semi-synthetic treatment/outcomes:** The pipeline simulates multi-treatment trajectories and potential outcomes using `simulation.py` (functions: `derive_severity_terms`, `sample_actions`, `generate_potential_outcomes`). Important: treatment labels/outcomes are generated by a simulator (documented in README).
- **Prepared outputs:** per-patient `.npz` files with `x`, `actions`, `y`, `y_all`, `sepsis_label` and split manifests at `data/sepsis_causal_artifacts/artifacts/prepared/{train,val,test}.csv`.
- **Code location for preparation:** [algorithm/sepsis_causal_project/src/sepsis_causal/prepare.py](algorithm/sepsis_causal_project/src/sepsis_causal/prepare.py) and dataset class in [algorithm/sepsis_causal_project/src/sepsis_causal/data.py](algorithm/sepsis_causal_project/src/sepsis_causal/data.py).

## Augmentation & sampling options (training-time)
